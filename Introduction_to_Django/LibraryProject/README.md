# LibraryProject

This is the initial Django project created for ALX Django Learn Lab.

## How to Run the Project
1. Install Django:
   pip install django

2. Start the development server:
   python manage.py runserver

3. Open your browser and go to:
   http://127.0.0.1:8000/

## Project Structure
- manage.py → Django command-line utility
- LibraryProject/settings.py → Project configuration
- LibraryProject/urls.py → URL routing
- LibraryProject/asgi.py & wsgi.py → Deployment entry points
